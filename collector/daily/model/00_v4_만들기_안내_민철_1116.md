## 1. p104b 코드 (원장 → 104c)
- **매달 돌릴 때는 `model/ledger_daily.py`** 를 씀 (p104b + 104c 를 한 파일로, 경로 없이 다시 쓴 것). `run_model.py` 가 맨 처음 부름

  - 규칙 (76번과 같음)
    1. 상위 50품목(`model/ref/상위50_품목코드.csv`), 단위코드 12(kg), 물량·금액 > 0

    3. 국산 = 산지명 첫 낱말이 시·도 이름(또는 국내산·국산). 시장·공판장 이름·빈칸은 미상
    4. 일 단위(→104c): 품종코드별 일 단가 < 앞뒤 61일 중앙/8 이면서 물량 > 중앙×8 인 날을 뺌 (76판 48개 코드-날)
  - seed 는 그대로 두고, 원자료가 있는 달만 다시 계산해 덮어씀 (그 달 원자료 날 수가 seed 보다 적으면 seed 유지 + 뒤 날짜만 붙임)
  - 출력 `원장_일별_품종코드.csv.gz` = 104c (열: 일자 · 품목코드4 · 품종코드 · 물량_kg · 금액_원 · 국산_kg · 국산금액_원)
- **처음부터(2020년~) 다시 만들 때만** `원장_처음부터_p104b/p104b_원장_일별_품종_오류줄뺌.py` (원래 코드)
  - `python p104b_….py <원장 월별CSV 폴더> <중간 폴더> <build_sanji_weather.py 가 있는 폴더> <상위50 csv> [초제한]` → 달마다 `중간/d_YYYYMM.csv` (시간 제한으로 끊기면 다시 실행하면 이어서)

## 4. 전체 순서와 명령
```
원장(수집기 raw)  →  ledger_daily.py (104b+104c)
                   →  n4 (322 단위 일별 가격 — 일 예측용)
월보 PDF          →  wolbo_auto.py
tV · tW 각각       →  panel_rebuild.py (= g5)  →  feat_update.py (주산지 기상 97 · 월보 83 · 통계청)  →  feat_roll.py  →  f1 (v4)
tV + tW           →  f2 (322 월 예측: v4 · 따라가기 · 반반)
```
- **f3 은 매달 안 돌림.** 단위별 모델(v4 256 · 따라가기 43 · 반반 23)·출하철·등급은 `model/ref/단위별_모델_출하철_등급.csv` 로 고정 (2023·24 로 고른 것을 바꾸지 않는 게 원칙)
- **꼭 지킬 것**
  - tV · tW 둘 다 f1 까지 돈 다음 f2 (따라가기가 tW 의 부모 v4 를 씀)
  - f1 의 환경 변수 — **`NC_NOQ=1` 이 빠지면 반입량 변수 8개가 들어간 75판 이전 모델이 됨**

    | 변수 | 값 |
    |---|---|
    | `NC_NOQ` | `1` (반입량 변수 뺌, 11-12 팀 원칙) |
    | `NC_R` | `<작업 폴더>/자료뿌리_tV/` (끝에 `/` 필요) — tW 면 `자료뿌리_tW/` |
    | `NC_OUT` | `<작업 폴더>/work/tV` — tW 면 `work/tW` |
    | `NC_FEAT` | `dropsig97` (15변수) |
    | `NC_CUT` | 기준월 다음 달 `YYYY-MM` (덜 찬 달을 학습에서 뺌) |
  - 기준월 = 원장 마지막 날이 든 달의 앞 달. 원장 마지막 날이 3일 이전이면 기다림
- **명령 (수집기 폴더 = `collect.py` 있는 곳에서)**
  ```
  python collect.py auction                 # 매일 (팀 수집기 그대로)
  python collect_monthly.py all             # 주산지 기상(DATA_GO_KR_KEY) · 통계청(KOSIS_API_KEY) · 월보 넣었는지 확인
  python model/run_model.py monthly         # 매달 3일 이후 → data/model/결과/NongClock_자동_기준YYYYMM/결과_기준YYYYMM/01_322_월예측_…csv
  ```
  옵션 `--base YYYY-MM`(기준월 직접) · `--raw <auction 폴더>` · `--data <작업 폴더>` · `--no-raw`(seed 만)
  - 결과 01 파일 = 지금 `python-ml/run_daily.py` 4단계가 `model/v4/` 에서 찾는 그 파일 (열 · 이름 모양 같음)
  - 시간: 윈도 PC 월 모델 포함 약 10분, 클라우드 2코어 7분 30초
