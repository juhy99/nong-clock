정부 비축·수매·방출·할당관세 자료 수집기

실행(Windows, Python 3.10 이상 필요)
1. ZIP을 압축 해제합니다. 공간이 있는 D드라이브 폴더를 권장합니다.
2. 1_접속점검.bat: 각 게시판의 첫 2페이지 접근·페이지 이동을 점검합니다.
   [목록]에 서로 다른 페이지의 문서가 잡히는지 확인합니다.
   오류가 있으면 수집결과/diagnostics와 검증요약.json을 함께 보내주세요.
3. 2_전체수집_이어받기.bat: 게시판 전체 공개기간을 수집합니다.
   연도·품목 제한은 없습니다. 개별 품목 외 기타 정책도 검토용으로 포함됩니다.
   중단 후 같은 BAT를 다시 실행하면 완료된 목록·본문·첨부는 재수집하지 않고 이어받습니다.
4. 3_CSV_다시만들기.bat: 저장된 자료만으로 CSV와 검증요약을 다시 생성합니다.

인증키 없음 / 유료 AI API 없음. 최초 실행 시 lxml과 pypdf 설치를 위해 인터넷 필요.
차단·캡차·로그인을 우회하지 않습니다. 공개 페이지와 첨부에 한해 수집합니다.
전체 기간은 이 5개 게시판에서 조회 가능한 기간을 뜻하며 정부 모든 사이트·모든 법령의 완전한 이력을 보장하지 않습니다.

추가 공식 상세페이지는 config.json의 seed_urls에 넣을 수 있습니다.

결과(수집결과 폴더)
01_전체문서_수집목록.csv: 게시일·출처·원문주소·오류·수집일·본문 해시

03_물량세율_원문근거_검토용.csv: 정책 문장·물량/세율 수치 후보와 단위·계획/실적 표현
04_첨부파일_수집상태.csv: 첨부 다운로드·텍스트 추출 상태

progress.sqlite: 이어받기 기록. 삭제하면 다시 수집합니다.

보존·해석 원칙
- CSV는 UTF-8 BOM. 코드·HS번호가 나오더라도 텍스트로 보존하며 엑셀·한셀로 다시 저장하지 마세요.
- 게시일과 실제 발표시각은 다를 수 있습니다. 발표일시는 확인 전 빈칸이며 시행일도 문맥 검수 전 자동 확정하지 않습니다.
- 표의 숫자와 품목을 자동으로 짝지어 확정하지 않습니다. 근거 문장에 등장한 수치 후보이며 품목별 사건표가 아닙니다.
- 계획량·실적량·낙찰량을 같은 물량으로 합산하지 마세요. 실제 실적 여부는 원문 검수 필요.
- WTO TRQ·FTA TRQ·할당관세는 별도 유형 후보로 표시합니다. 제목만으로 판별되지 않는 건 미확정입니다.
- URL은 중복 다운로드하지 않으며 동일 본문 해시도 기록합니다. 같은 정책의 재발표·연장·수정 공고는 자동 병합하지 않습니다.
- 수집되지 않은 날짜는 정책이 없었다는 뜻이 아닙니다. 누락일을 사건 없음(0)으로 채우면 안 됩니다.
- 분석용 모델에 넣으려면 원문 검수를 마친 후 품목/정책/발표일/시행기간/물량/수치기준을 확정해야 합니다.

첨부 처리
PDF: 문자 추출. 스캔 PDF는 OCR필요로 표시하고 원본 저장.
HWPX: XML 텍스트 추출. XLSX: 셀 문자열 읽기(기존 파일 수정 없음).
HWP·구형 XLS: 원본 저장, 자동 텍스트 변환 미지원 상태 표시.
ZIP: 원본 저장, 압축 안 문서 자동 재귀추출 미지원.
따라서 숫자 후보 CSV만 보면 첨부 표/HWP에만 있는 물량이 빠질 수 있습니다. 04 첨부상태를 반드시 확인하세요.

설정
max_pages=0: 임의 페이지 상한 없음. 진짜 끝페이지가 확인될 때만 목록끝확인.
페이지 반복·빈 목록·HTTP 오류는 완료가 아니라 오류/미완료로 표시.
게시판 구조가 달라지면 config의 page_param 또는 파서 수정이 필요할 수 있습니다.
최신 공고를 다시 찾을 때: python collector.py --refresh
기본 실행은 기존 완료 목록을 건너뛰므로 신규 글을 찾으려면 --refresh를 사용하세요.
공고 수정 버전 재수집은 현재 자동 지원하지 않습니다. 원문 주소·수집시각·해시로 버전을 확인하세요.
