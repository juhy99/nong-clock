# 인증키 발급 따라하기 (처음 받는 사람용, 2026-11-06 사이트에서 확인)

다 받으면 `.env.example` 을 `.env` 로 복사해서 이름 옆에 붙여 넣고 `1_연결시험.bat` → 결과가 모두 ‘성공’이면 끝.
**기상청 API허브와 data.go.kr 은 키는 1개지만, 아래 적은 칸마다 [API 활용신청]/[활용신청] 을 따로 눌러야 한다.** 안 누른 칸은 같은 키라도 인증 오류가 난다.

---

## 1. 기상청 API허브 → `KMA_APIHUB_KEY` (5칸 신청)

1. https://apihub.kma.go.kr 회원가입 → 로그인 (로그인 안 하면 [API 활용신청] 이 로그인 창으로 감)
2. 아래 주소를 **하나씩 열고**, 적어 둔 제목 바로 아래 파란 [API 활용신청] 버튼을 누른다.
   한 페이지에 비슷한 칸이 많다 → **제목 번호와 주소 끝 파일 이름(.php)이 같은지** 꼭 확인.

| # | 열 주소 | 페이지 위 탭 | 누를 칸 (제목) | 위에서 몇 번째 버튼 | 버튼 아래 주소 끝 |
|---|---|---|---|---|---|
| ① | https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=238 | 지상관측 › 종관기상관측(ASOS) | **1.4 일자료(기간 조회)** | 4번째 (19개 중) | `kma_sfcdd3.php` |
| ② | https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=239 | 지상관측 › 방재기상관측(AWS) | **4. 지상 및 AWS 일통계 자료 조회 › 4.1 요소별 조회** | 17번째 (42개 중) | `sfc_aws_day.php` |
| ③ | https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=317 | 지상관측 › 지상관측 지점정보 | **1.1.1 지상** | 1번째 (5개 중) | `stn_inf.php?inf=SFC` |
| ④ | https://apihub.kma.go.kr/apiList.do?seqApi=10&seqApiSub=288 | 예특보 › 기상특보 | **1.1 특보구역** | 1번째 (7개 중) | `wrn_reg.php` |
| ⑤ | 위 ④와 같은 페이지 | 예특보 › 기상특보 | **1.2 특보자료** (= 특보 발표 이력) | 2번째 (7개 중) | `wrn_met_data.php` |

- **헷갈리는 것 — 누르지 않아도 됨:**
  - 기상특보 페이지의 1.3 기상정보, 1.4 날씨해설, 2. 특보현황 조회(지금 걸린 특보만), 3. 특보 이미지
  - ‘예·특보 구역정보’ 탭의 `wrn_reg_aws.php`
  - ASOS 1.3 일자료(`kma_sfcdd.php`, 하루만), AWS 1.x 매분자료
- 예보(단기·중기)는 API허브가 아니라 **data.go.kr** 에서 받는다(아래 2번 ①②). API허브 ‘단기예보·중기예보’ 탭은 안 눌러도 됨.
- 인증키는 하나. 신청 뒤 받은 인증키(authKey)를 `KMA_APIHUB_KEY=` 에.

## 2. 공공데이터포털 data.go.kr → `DATA_GO_KR_KEY` (5칸 신청, 모두 자동승인)

1. https://www.data.go.kr 회원가입 → 로그인
2. 아래 주소마다 [활용신청] → 활용목적(예: 연구) 적고 신청 → 자동승인
3. 마이페이지 › 데이터활용 › Open API › 인증키에서 **일반 인증키(Decoding)** 복사 → `DATA_GO_KR_KEY=`
   (승인 직후 1~2시간은 안 될 수 있음)

| # | 주소 | 이름 (사이트 그대로) | 하루 한도(개발) | 쓰는 곳 |
|---|---|---|---|---|
| ① | https://www.data.go.kr/data/15084084/openapi.do | 기상청_단기예보 조회서비스 | 10,000 | 예보 |
| ② | https://www.data.go.kr/data/15059468/openapi.do | 기상청_중기예보 조회서비스 | 10,000 | 예보 |
| ③ | https://www.data.go.kr/data/15078057/openapi.do | 농촌진흥청 국립농업과학원_농업기상 기본 관측데이터 조회 | **1,000** | 날씨 관측 |
| ④ | https://www.data.go.kr/data/15012690/openapi.do | 한국천문연구원_특일 정보 | 10,000 | 공휴일 |
| ⑤ | https://www.data.go.kr/data/15141813/openapi.do | 한국농수산식품유통공사_도매시장 전자송품장 출하예약정보 | 10,000 | 출하예약 |

- 비슷한 이름 주의: ⑤ 바로 옆 ‘온라인 도매시장 거래정보’(15141811)는 아님. ‘기상청_초단기…’ 따로 있는 것도 아님(①안에 들어 있음).

## 3. 농식품 공공데이터포털 data.mafra.go.kr → `MAFRA_API_KEY` (2칸 신청)

1. https://data.mafra.go.kr 회원가입 → 로그인 → 인증키 발급
2. 아래 두 페이지에서 각각 아래쪽 **[오픈 API 신청]**

| # | 주소 | 이름 | API 이름 |
|---|---|---|---|
| ① | https://data.mafra.go.kr/opendata/data/indexOpenDataDetail.do?data_id=20240625000000002459 | 전국 공영도매시장 정산정보 | 도매시장 정산 가격 정보 (`Grid_20240625000000000653_1`) |
| ② | https://data.mafra.go.kr/opendata/data/indexOpenDataDetail.do?data_id=20240625000000002467 | 도매시장 산지공판장 정산 가격 | `Grid_20240625000000000660_1` |

- 같은 포털에 ‘정산가격 기간별 도매시장별 품목별 총물량’(Grid_..658) 도 있는데 그건 아님.
- 연결시험에서 ‘INFO-100 인증키가 유효하지 않습니다’ = 키를 잘못 붙였거나 아직 발급 전.

## 4. KAMIS → `KAMIS_KEY`, `KAMIS_ID`
https://www.kamis.or.kr 회원가입 → 로그인 → 마이페이지 › Open-API 신청 1번 → 나온 인증키 = `KAMIS_KEY`, 요청자 ID = `KAMIS_ID`

## 5. 서울 열린데이터광장 → `SEOUL_OPENAPI_KEY`
https://data.seoul.go.kr 회원가입 → 로그인 → 인증키 신청 1개 (가락 경매전·후 반입물량 `GarakAuctionBefore`·`GarakAuctionAfter` 에 씀)

## 6. 한국은행 ECOS → `ECOS_API_KEY`
https://ecos.bok.or.kr/api 회원가입 → 인증키 신청 1개 (환율 통계표 `731Y001`)
