# 날씨 화면 파일 (지난 날씨)

날씨 수집기(`collector/weather`, 데이터 담당)가 매일 만드는 **`날씨_대통합_일별.csv`** 를 화면이 읽는 작은 JSON 으로 바꿉니다. 날씨를 **수집하지는 않습니다**.
파이썬 3.9 이상, 설치할 라이브러리 없음.

```
weatherraw 볼륨 site/날씨_대통합_일별.csv (137MB, 113만 행)  ┐
또는 input/*.csv (손으로 넣은 CSV, 커밋 안 함)              ┴─ 가장 최근 것 ──export_weather.py──▶ data/ (커밋 안 함)
                                                    ├ regions-daily.json    시·도 17곳 최근 120일 일별 + 그 날의 평년값 (≈340KB, 전송 ≈45KB)
                                                    ├ regions-monthly.json  시·도 최근 25개월(다 끝난 달) + 월 평년(1991~2020)
                                                    ├ meta.json             만든 시각 · 원본 파일 · 구분별 기간·행 수 · 오류
                                                    └ collect_log.json · preprocess_log.json   수집기 기록 복사 (관리자 화면)
```

- v2 표(`시도_일`·`시군구_일`, 일별 평년값)와 예전 v1 표(`시도_일`·`시도_월`·`시군구_월`)를 모두 읽습니다. 시군구 행은 세기만 합니다.
- v2 월값은 일별에서 계산: 기온은 평균, 비는 합, 폭염(33℃)·영하(0℃)·비(1mm)·강풍(순간 14m/s) 일수는 **시·도 평균값 기준**으로 셈. 관측일이 80% 미만인 달은 값 없음.
- 월 평년은 일별 평년(같은 월·일 ±3일, 1991~2020)으로: 기온은 평균, 비는 그 달 날짜 합 (2월 29일 제외).
- 137MB 를 줄 단위로 읽어 약 10초, 메모리 약 0.5GB.

화면에서 쓰는 곳:
- **홈 › 우리 지역 농업 날씨 › 지난 날씨**: 마지막 날 최저·최고·비, 최근 7일 비, 최근 7일 평년 대비, 최근 30일 그래프, 지난달 평년 대비, 주의 신호(비 안 온 날 7일 이상 · 하루 80mm 넘는 비 · 영하 · 33℃ 이상 · 순간풍속 14m/s 이상, 최근 7일)
- **관리자 › 데이터 수집·대시보드·서버 상태**: 단기·중기예보 / 지난 날씨 / 장기전망 줄의 상태 (수집 기록 + 화면 파일). 예보는 4시간 넘게 성공이 없으면 "지연", 9시간이면 "멈춤"(대시보드 경고), 관측·전처리는 26·50시간

## 실행 (내 PC)

```powershell
cd collector\weather_site
# input\ 폴더에 날씨_대통합.csv 를 넣고
python export_weather.py          # 한 번 만들기 → data\
python -m unittest -v             # 검사
```

프론트 테스트 모드(`VITE_DATA_SOURCE=live`)로 `npm run dev` 를 켜면 이 폴더의 `data/` 를 읽습니다.

## 서버

`docker compose` 의 **`weather-export`** 가 5분마다 확인합니다 (도커 볼륨 `weatherdata` → 화면 `http://서버주소/data/weather/…`).

- 입력: 환경변수 `WEATHER_CSV`(= 수집기 볼륨의 `site/날씨_대통합_일별.csv`)와 `input/*.csv` 중 **가장 최근에 바뀐 파일**
- 막 바뀐 CSV 는 2분 기다렸다 읽습니다 (전처리가 파일을 통째로 다시 쓰는 중일 수 있어서). 마지막 날짜가 지난번보다 앞이면 덜 써진 파일로 보고 그대로 둡니다
- 실패하면 기존 화면 파일은 그대로 두고 `meta.json` 에 오류만 남깁니다 → 관리자 화면에 표시. 같은 파일은 바뀔 때까지 다시 읽지 않습니다
- `WEATHER_LOG_DIR`(= 수집기 볼륨)의 `collect_log.json`·`preprocess_log.json` 을 바뀔 때마다 복사

## CSV 형식 (데이터 담당 `00_먼저읽기.md`·`build_weather_daily.py` 기준)

- 쓰는 구분: `시도_일`(필수), (v1) `시도_월`. 시군구 구분은 기간·행 수만 기록 (아직 화면에서 안 씀)
- 필요한 열: `구분, 날짜, 시도, 최고기온, 최저기온, 강수량` (+ 있으면 `평균기온`(없으면 `평균기온_근사`), `평균습도, 일조시간, 최대순간풍속, 평년_평균기온, 평년_강수량`, v1 의 `고온일수, 영하일수, 강수일수, 강풍일수`)
- `시도` 는 약칭 17개 (서울·부산·…·제주·세종). 빈칸은 빈칸 그대로 (0 으로 채우지 않음)
- 열 이름이나 시도 이름이 바뀌면 `export_weather.py` 의 `REQUIRED`·`DAILY_COLS`·`MONTHLY_COLS`·`SIDO` 를 같이 고칩니다
