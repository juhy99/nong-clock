# 품목 대표 사진

이 폴더에 **품목 코드와 같은 이름**으로 사진을 넣으면, 시세 카드·품목 선택 버튼·관심 품목 등 품목이 나오는 모든 곳에 자동으로 쓰입니다.
사진이 없는 품목은 이모지로 대신 보여주므로 한 장씩 넣어도 됩니다. 코드는 고칠 필요 없습니다 (`components/ItemImage.jsx`).

## 사진 고르는 규칙
- **배경을 지운 PNG(투명 배경) 추천** — 카드 배경색 위에 품목만 보여서 가장 깔끔합니다. (remove.bg 같은 무료 도구)
- 정사각형, 가로세로 400~600px, 장당 200KB 이하
- 16장 모두 비슷한 각도·크기로 (품목이 사진의 70~80%를 차지하게)
- **저작권:** Unsplash·Pexels·Pixabay 처럼 무료로 쓸 수 있는 곳에서 받고, 받은 곳을 아래 표에 적어 두세요. 검색 사이트에서 아무 사진이나 받지 마세요.
