# 실험: 원인 모델 vs 팀원 모델(v4·u7c) — 비교하고 합치기 (2026-11-12, 돌리기 전에 정함)

## 질문
322단위 가격 예측에서 (가) 원인 모델, (나) 팀원 모델, (다) 둘을 합친 것 중 무엇이 가장 잘 맞나? 거리(1~14거래일 / 1~12달)마다 따로 본다.

## 두 모델 (둘 다 '지금 시세'를 입력으로 안 씀)
- **원인 모델** (`2_engine.py`, 패널 2026-11-03): 작년 같은 철 가격 + 해마다 변화 a + 탄력 e × 예상 생산 변화 d̂(되돌림) (+ 과수 태풍 X4) + 계절 모양. 출발일 = 2023-01-01부터 매주 일요일
- **팀원 월 모델 v4** (최종자료 `02_322_월예측_시험줄_2023부터`): 작년 같은 달 가격·계절평균 + LightGBM(출하·면적·품목물량·월보 전망·주산지 기상 23변수). 기준월 → 1~12달 뒤
- **팀원 일 모델 u7c** (최종자료 코드를 그대로 다시 돌림): 새기준 = w × (작년 같은 주 + β × 28일 출하량 전년비) + (1 − w) × 주 계절평균. 기준일 = 그 단위 거래일마다, H = 1~14번째 다음 거래일

## 비교하는 줄 (같은 단위 · 같은 출발 시점 · 같은 목표)
- **월:** 팀원 시험 줄 중 출하철 = 1 인 줄 × 원인 모델 `test_monthly`(그 달 마지막 일요일 출발) 에서 출발 달 = 팀원 기준월, 목표월 같은 줄. 원인 모델은 기준월 끝보다 최대 6일 덜 본 상태(불리한 쪽)
- **일:** 팀원 u7c 일별 시험 줄 중 기준일 = 원인 모델 출발일(일요일) − 1일(토요일) 인 줄 × 원인 모델 같은 목표일 예측. H 는 팀원 H
- **실제:** 둘 다 우리 DB 값 (월 = `test_monthly` 실제, 일 = DB 일 단가). 참고로 팀원 자기 실제로도 한 번 계산
- **뺄 단위:** 일 비교에서 만감 4단위(천혜향·레드향·황금향·카라향) — 팀원 일 파일은 326 이름이라 DB 단위와 뜻이 다름. 월 비교에는 넣고 따로 표시

## 잣대
- 오차 = |예측 ÷ 실제 − 1|. 단위마다 평균 → 단위 평균을 다시 평균 (322단위 같은 무게). 고르기 = 목표 2023~24, 확인 = 목표 2025~
- 참고로 팀원 잣대(100 − 단위 평균 오차, 단위 중앙)도 같이 적음

## 후보 (log 공간)
- A 팀원 그대로 · B 원인 그대로
- C 섞기: w × 팀원 + (1 − w) × 원인, w ∈ {0, 0.1, …, 1} 하나
- D 거리별 섞기: 월 h 1~3 / 4~6 / 7~12, 일 H 1~5 / 6~14 마다 w
- E 단위별 고르기: 단위마다 {A, B, 반반} 중 하나 (고르기 줄 6개 이상일 때, 아니면 C)

## 고르는 규칙 (고르기 구간 안에서만)
1. 교차 채점: 2023 으로 w·고르기를 정해 2024 에 채점, 2024 로 정해 2023 에 채점 → 두 점수 평균 = 교차 점수
2. 교차 점수가 가장 낮은 후보. 단 더 단순한 후보(A·B < C < D < E)와 0.2%p 안이면 단순한 쪽
3. 고른 후보의 w·고르기는 고르기 전체(2023~24)로 다시 정하고, 확인 구간(2025~)은 보고만 함 (다시 고르지 않음)

## 화면으로 이어 붙이는 방식 (결과 보고 바꾸면 '사후'로 적음)
- 1~14거래일: 일 비교의 승자
- 그 뒤 ~12달: 월 비교의 승자. 원인 모델 일 예측 × (승자 월 값 ÷ 원인 모델 월 값) 으로 날짜별 모양을 입힘
- 12달 넘게: 원인 모델만 (팀원 예측 없음)
